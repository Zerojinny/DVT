DVT v0.4.0
==========

DVT GUI
-------
- 사이드바 맨 위에 qBittorrent (시더) 페이지 추가: 최신 안정 버전의 qBittorrent(표준 x64 빌드, SourceForge)를 받아 7-Zip으로 임시 폴더에 푼 뒤 프로그램 파일만 빌드 폴더의 qbittorrent\로 복사하고(포터블 모드, qbittorrent\profile, Windows에는 설치하지 않음), 이 PC의 링크 속도에 맞는 설정 파일(qbittorrent.ini.1G 또는 .100)을 이 PC의 IP 주소와 네트워크 어댑터(네트워크 인터페이스, 바인딩할 IP, 트래커 URL)를 넣어 profile\qBittorrent\config\qBittorrent.ini로 복사합니다. "이 PC 기준으로 수정" 버튼은 기존 파일의 이 항목만 다시 설정합니다. 정보 파일: data\qbt.ini.
- qBittorrent (시더) 페이지에 "이미지 폴더 점검" 버튼 추가: 토렌트로 만들 폴더를 점검하고(폴더 이름 DL_NAME, 필수 파일 backup.wim과 dvt_check.txt, drivers\와 files\setpc.bat는 있으면 표시) dvt_check.txt가 없으면 약 4 KB의 텍스트로 만듭니다.
- qBittorrent (시더) 페이지에 "디스크 크기 계산" 버튼 추가: wimlib-imagex info로 backup.wim(이미지 WIM_INDEX)을 읽고 이미지 폴더의 다른 파일을 더해 APPLIED_SIZE_MB와 복원 가능한 최소 디스크(다른 드라이브에 다운로드 / 같은 디스크에 다운로드)를 보여주며, 확인을 받은 뒤 data\pe\config.cmd와 data\Media\pe\config.cmd의 APPLIED_SIZE_MB에 씁니다. 복원 후 크기는 하드 링크를 한 번만 세고(Total Bytes - Hard Link Bytes) 파일·폴더마다 4 KB를 더합니다. config.cmd의 설명도 고쳤습니다.
- 언어를 고르기 전에는 항상 영어로 시작합니다(이전: Windows 표시 언어). 선택은 data\gui_settings.ini에 저장됩니다.
- qBittorrent (시더) 페이지에 "방화벽 예외 추가" 버튼 추가: qBittorrent.ini의 피어 포트(TCP, UDP), 트래커 포트(TCP)와 qbittorrent.exe에 대한 Windows 방화벽 인바운드 규칙을 관리자 권한 한 번으로 추가합니다("DVT qBittorrent ..." 규칙은 새로 바꿈). 규칙이 있는지 상태 줄에 표시됩니다. qBittorrent 설치 / 업데이트는 마지막에 이 규칙을 자동으로 추가합니다.
- 내려받은 파일 재사용: _output\tools_download의 WinPE 도구 zip은 SHA256이 tools.ini와 같으면, _output\qbt_download의 qBittorrent 설치 파일은 내려받은 뒤 기록한 .sha256과 같으면 다시 받지 않습니다.
- 시작 화면: 사이드바 아래에서 고르며(페이지 하나 또는 마지막 화면) data\gui_settings.ini(start_page, last_page)에 저장됩니다. 설정을 저장할 때 gui_settings.ini의 다른 줄은 그대로 둡니다.
- USB / CD 미디어의 "토렌트와 aria2" 탭: 빌드 폴더 안의 파일은 PC의 전체 경로 대신 짧은 경로(data\Media\config\...)로 표시합니다.

저장소
------
- .gitignore: 현장별 파일(ip.txt, *.torrent, gui_settings.ini), 빌드 결과물, 외부 도구가 커밋되지 않도록 했습니다.

DVT v0.3.0
==========

주요 변경
---------
- DVT GUI(DVT_GUI.exe): 빌드 PC의 모든 작업을 창 하나에서 합니다. GUI는 설정 파일을 고치고 스크립트를 실행할 뿐이므로 배치 파일만으로도 그대로 동작합니다.
  - 페이지: 클라이언트 로컬부팅, USB / CD 미디어, 테스트 부팅, 필수 구성 요소.
  - 모든 설정에 짧은 설명과 자세한 도움말이 있고, 선택지가 정해진 설정은 드롭다운으로 고릅니다. 잘 바꾸지 않는 설정은 "고급 설정 표시"를 체크해야 보입니다.
  - 저장할 때 set "NAME=VALUE" 줄만 바꾸고 _output\gui_backup에 백업을 남깁니다.
  - USB / CD 미디어: 빌드 폴더나 기존 DVT USB 드라이브의 ip.txt, 토렌트, WinPE 설정을 직접 편집합니다.
  - 클라이언트 패키지 복사: _output\boot(또는 boot_test)를 원하는 폴더로 복사합니다.
  - 한국어·영어 지원. 문구는 lang\*.ini에 있으며, en.ini를 번역해 새 언어를 추가할 수 있습니다.
- GUI에서 Windows ADK 설치: ADK 버전(Windows 10 1809 ~ 최신)을 골라 Microsoft에서 adksetup.exe / adkwinpesetup.exe를 받고(Microsoft 서명과 SHA256 확인, data\adk.ini) 배포 도구와 WinPE 추가 기능만 설치합니다. 인터넷이 안 되는 빌드 PC용 오프라인 패키지를 지원하며, 다른 버전이 설치되어 있으면 먼저 제거합니다(ADK 설치 오류 2008).
- GUI에서 WinPE 도구 다운로드: aria2, wimlib, NirCmd(x64)를 공식 사이트에서 받아 SHA256을 확인하고(data\tools.ini) pe_tools로 복사합니다.

구조 변경
---------
- bats 폴더 이름을 data로 바꿨습니다. 01_make_pe.bat, 02_make_media.bat, 03_make_test_pe.bat과 adk.ini, tools.ini도 data로 옮겼습니다. 빌드 폴더에는 DVT_GUI.exe, lang, doc, pe_tools, drivers, source, _output이 남습니다.
- BATS_DIR 변수 이름을 DATA_DIR로 바꿨습니다(data\host\config.cmd).
- nircmd.exe는 다른 도구와 함께 pe_tools에 둡니다(NIRCMD_SRC). nircmd-x64 폴더는 더 이상 쓰지 않습니다.

문서
----
- README와 매뉴얼에 DVT GUI 장과 스크린샷(doc\images)을 추가했습니다. 모든 단계를 GUI로 하는 방법과 배치 파일로 하는 방법을 함께 설명합니다.
- 폴더 구성과 경로를 data 폴더 기준으로 고쳤습니다.

DVT v0.2.0
==========

주요 변경
---------
- 지울 디스크 판별 개선: 표식 파일(DVT.tag) 대신 Windows 디스크의 디스크 ID(GPT GUID / MBR 서명)로 찾습니다. BitLocker 드라이브에서도 동작합니다. RAW 볼륨 검색은 순간복구 프로그램이 설치된 PC를 위한 보조 규칙으로 남겼습니다(AUTO_DISK_FALLBACK).
- BitLocker 일시 중단: make_boot.bat이 보호를 재시작 1회 동안 멈춥니다. 점검에 실패해 Windows로 돌아가도 복구 키를 묻지 않습니다(BITLOCKER_SUSPEND).
- 디스크 공간 검사: 이미지가 들어갈 공간이 없으면 디스크를 지우기 전에 멈춥니다(SPACE_CHECK).
- 이미지 번호 선택: WIM_INDEX로 backup.wim 안의 이미지를 고릅니다(기본 1).
- 복원 기록: 복원된 Windows의 HKLM\SOFTWARE\DVT에 버전, 부팅 방식, 이미지, 시각 등을 남깁니다.
- 부팅속도 개선: WinPE 시작 때 DHCP를 기다리지 않습니다. Windows의 고정 DNS를 WinPE에 전달하고, 미디어의 ip.txt에도 DNS를 적을 수 있습니다.
- USB / CD 미디어: FORCE_DISK 지원. 기존 미디어 이미지를 다시 쓸지 묻습니다. FAT32 32GB 제한 검사를 없앴습니다.
- 버전 표시: 모든 화면에 DVT 버전이 나옵니다(bats\common\version.cmd).

구조 변경
---------
- 스크립트를 bats\host, bats\pe, bats\Media, bats\test로 옮겼습니다. 세 부팅 방식이 함께 쓰는 WinPE 스크립트는 bats\common 하나로 합쳤습니다.
- ADK 파일은 source에, 빌드 결과물은 _output(boot, boot_test, media)에 둡니다.
- 테스트 이미지는 클라이언트의 C:\temp\boot_test에서 실행합니다.

문서
----
- README와 Markdown 매뉴얼(영어·한국어)과 PDF를 추가했습니다.
- qBittorrent 5.3.0 기준 시더·트래커 설정 안내와 설정 파일(doc\qbittorrent.ini)을 추가했습니다.
